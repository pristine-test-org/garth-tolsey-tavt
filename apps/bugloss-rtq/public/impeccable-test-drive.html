How the board works

Everything on the shared list lands on the board in the order it was added, newest first, so you can see what is open and what is done without opening a single item.

What each column shows

ColumnWhat it holdsRefreshes
OpenItems nobody has ticked off yetOn every visit
DoneItems marked with a tickOn every visit
RecentThe five newest items, open or doneOn every visit

Items are read straight from the shared list, so the board is never out of date.
